# Flashcard Quiz App

A simple Android application for creating, managing, studying, and testing flashcards.

## Features

- Create new flashcards
- Add questions, answers, and categories
- View all saved flashcards
- Filter flashcards by category
- Edit existing flashcards
- Delete flashcards
- Study mode with answer reveal
- Quiz mode with automatic scoring
- Offline data storage using SQLite
- Simple and user-friendly interface

## Technologies Used

- Java
- Android Studio
- XML
- SQLite
- Android SDK

## Project Structure

The application includes:

- **Home Screen** – Navigation to study, flashcards, quiz, and add flashcard
- **Add Flashcard** – Create and save new flashcards
- **My Flashcards** – View, filter, edit, and delete flashcards
- **Study Mode** – Review questions and reveal answers
- **Quiz Mode** – Answer questions and track your score
- **SQLite Database** – Store flashcards locally on the device

## How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Let Gradle sync and complete the project setup.
4. Connect an Android device or start an Android emulator.
5. Click **Run** in Android Studio.
